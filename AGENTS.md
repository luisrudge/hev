# Hev

A human-powered take on Jev/Clef decision models: the same System One API, but every decision is made by a human on the website. Not meant for production.

## Copy

Voice: playful. The page dresses up like a serious AI model launch, and it winks openly: jokey asides are welcome. Keep jokes short, and never let one hide what a control does.

Casing: sentence case for headings, buttons and labels. Names capitalized: Hev, Jev, Clef, System One. Lowercase `hev` only where it is the API value (`"model": "hev"`).

Spelling: US English.

Punctuation: no exclamation marks. No em dashes. Full sentences end with a period; buttons, labels and chips don't.

Numbers: digits, with units and no space (41s, 209.3ms).

One word per action: "Ask" submits a question, "Answer" responds to one.

Words that never change: (Human) Decisions API (the headline), Human Decisions API (the name in titles), Ask a human, human (never person, user or worker for whoever answers), question (in the UI; the API section may say request), noul, choice, score.

aria-labels: tightened, never removed.
